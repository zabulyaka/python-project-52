# Task Manager

### Info:

The name of the app speaks for itself. It allows to manage tasks:
- create tasks
- choose a status in which the task is currently on
- assign a person responsible for task completion.

The app also provides a handy filter with labels system in order to make the search easier through the tasks. All the functionality is available to registered users only, which guarantees the security of information.

[Watch App](https://python-project-52-hl6z.onrender.com/)

### Tech Stack:

[Django](https://docs.djangoproject.com/en/5.2/) - the backend part

[Bootstrap](https://getbootstrap.com/) - the frontend part

[Render](https://render.com/) - hosting service

[PostgreSQL](https://www.postgresql.org/) - database support
